SyRuP: Enhancing System-Prompt Following
via Reward-Guided Prediction in LLM Decoding

Seoyeon Kim, Minjae Kang, Jaehyung Kim
Yonsei University
Paper arXiv Code

SyRuP (System-prompt following via Reward-guided Prediction)
keeps the system prompt as a distinct conditioning source
and steers a frozen LLM toward it, token by token.

Abstract

Large Language Models (LLMs) are increasingly controlled through system prompts that specify roles, formats, and safety requirements. However, models follow these prompts only implicitly through in-context learning, which can be insufficient for complex or compositional prompts. Existing approaches often require model tuning or response-level reranking, limiting their practicality for lightweight inference-time control.

We introduce SyRuP, a decoding-time framework for improving system-prompt adherence while keeping the base LM frozen.

SyRuP trains a cross-attention reward head from system-prompt-conditioned preference pairs, treating the system prompt as a separate memory to produce token-level adherence scores. At inference, SyRuP reranks the base LM's top-k candidates by combining base logits with both the learned reward signal and a contrastive signal that captures system-induced logit shifts.

Experiments on system-prompt following benchmarks show that SyRuP consistently outperforms prompting and decoding-time baselines with moderate inference overhead. These results suggest that explicit token-level guidance is an effective and practical mechanism for reliable system-prompt following.

Motivation

1 System Prompts Are Followed Only Implicitly

System prompts are persistent, high-priority instructions that govern model behavior throughout an interaction. Yet at inference time, an LLM must follow a given system prompt solely through conditioning, without explicit optimization for that particular prompt. As system prompts become more complex and compositional, models often fail to adhere to them consistently.

Training-time Approaches

Improving general instruction following through SFT or RLHF.

❌ Costly parameter updates

❌ Possible alignment tax

Decoding-time Approaches

Steering a frozen model during generation.

❌ Focused on generic instruction following

❌ No explicit judgment of system-prompt adherence

2 Gaps in Existing Decoding-time Signals

Two lines of decoding-time work are natural candidates for system-prompt following, but neither treats the system prompt as an explicit criterion for next-token selection.

🧩

Reward-guided Decoding

Reward models process the prompt and response as a single sequence, so the system prompt is absorbed into the prefix. They also target fixed, task-level attributes rather than instance-specific constraints.

🔍

Contrastive Decoding

The logit difference with and without the context is a training-free cue for the LM's sensitivity to the system prompt, but it remains implicit and gives no learned judgment of whether a token satisfies the prompt.

Our Approach: SyRuP

We reformulate system-prompt following not as simple prefix conditioning, but as a token-level conditional adherence problem between a fixed system instruction and an evolving generation state. An explicit, learned reward signal is then reinforced by the LM's intrinsic contrastive signal.

How SyRuP Works

TRAINING

Cross-attention Reward Head

Rather than merging the system prompt, user query, and generated prefix into a single hidden feature, SyRuP keeps the system prompt as a separate key-value memory that a lightweight reward head attends to at each decoding step.

Cross-attention Scoring

$$ \mathbf{A}_t = \mathrm{softmax}\!\left(\frac{\mathbf{Q}_t \mathbf{K}_s^\top}{\sqrt{d}}\right)\mathbf{V}_s $$ $$ r_t(v) = \mathbf{z}_t^\top \mathbf{e}_v $$
  • System Prompt as Memory: Keys and values come from the system-prompt hidden states \(\mathbf{H}^{(s)}\), while queries come from the concatenated user-input and generated-prefix hidden states. The system-prompt memory can be cached and reused across decoding steps.
  • Token-level Reward: The fused representation at the most recent position, \(\mathbf{z}_t\), scores each candidate token through the frozen output embeddings \(\mathbf{e}_v\).
  • Pairwise Training: Trained on system-prompt-conditioned preference pairs with a Bradley–Terry objective over averaged token rewards. Only the cross-attention projections and fusion MLP are updated; the base LM stays frozen.
DECODING

Reward-guided Decoding

At each step, SyRuP reranks only the base LM's top-k candidates, combining base plausibility with the learned reward and a contrastive signal that measures how the system prompt shifts the base LM's logits relative to a neutral prompt.

Decoding Rule

$$ y_t = \arg\max_{v \in \mathcal{C}_t} \Big[\, \ell_t(v) + \lambda_r\, r_t(v) + \lambda_c\, \Delta_t(v) \,\Big] $$ $$ \Delta_t(v) = \ell_t(v) - \ell_t^{\mathrm{neu}}(v) $$
  • Top-k Reranking: Intervenes only among tokens that are already plausible under the base model, preserving fluency and avoiding full-vocabulary reward computation.
  • Complementary Signals: The reward \(r_t\) is an explicit, trained adherence evaluator, while \(\Delta_t\) reflects the base LM's intrinsic sensitivity to the system prompt. Setting \(\lambda_c = 0\) gives reward-only decoding, \(\lambda_r = 0\) gives contrastive-only decoding, and both at zero recovers greedy decoding.

Analyses

Reward and contrastive signals are complementary. Reward-only and CS-only reach 3.43 and 3.68, while their combination reaches 3.95. Moderate weights work best (stars), so neither signal should dominate the base LM.

9.8% of SyRuP's tokens are SyRuP-unique, meaning no single signal (base LM, reward, or contrastive) ranks them first. These choices arise only from integrating the signals.

Explicit system-prompt conditioning matters. The cross-attention reward head outperforms variants that drop the system prompt (No-system) or encode everything as a single stream (Single-stream). The gap is clearest under Reward-only, where the reward head is the sole steering signal.
